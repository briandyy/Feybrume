# Media dan audio

Sumber dapat berupa ID Roblox positif, URI Roblox yang cocok dengan jenis aset, HTTPS, path lokal, manifest atlas, ID YouTube, atau referensi yang sudah didaftarkan. `Media:Resolve` hanya menormalisasi, memeriksa policy dan memilih backend. Keberhasilan resolusi berarti sebuah jalur tersedia. Proses load harus membuktikan izin, readiness dan hasil playback secara terpisah. Semua baris di bawah adalah desain yang belum diimplementasikan di Feybrume.

Roblox mendokumentasikan `ImageLabel` untuk image content termasuk region spritesheet, `VideoFrame` untuk video asset Roblox, dan `AudioPlayer` sebagai sumber graph audio. `EditableImage` bisa menjadi sumber dari objek dengan `Content.fromObject`, dengan persyaratan izin dan memori. Fase awal tidak mengandalkan decode/fetch PNG arbitrer di client. `rbxasset://` ialah referensi konten runtime yang didukung, path disk milik pengguna memakai tipe `local`. Sintaks yang diterima belum membuktikan aset bisa dimuat. Scrubbing/fit, clipping, caption dan concurrency VideoFrame perlu uji device terbit. ## Kontrak MediaSource

`kind: image|gif|video|audio|sprite|viewport|youtube`. `source: {type: robloxAsset|robloxUri|https|local|atlas|youtube|registered, value}`; `Viewport3D` juga menerima model dari adapter lokal melalui `registered` atau properti model bertipe Instance. Shorthand `assetId/url/localPath` diterima tepat satu, konflik atau aset ID `0` menghasilkan `INVALID_ARGUMENT`. Contoh §§12.6 dan 26 dinormalisasi: `type` pada objek luar adalah alias `kind`; `slot` implisit berarti placement `slot`, `content` menjadi slot konten default. Canonical placement `slot|absolute|background|overlay`, `fit: contain|cover|fill|none`, `loadPolicy: whenVisible|manual|eager` default whenVisible, `autoplay=false`, `muted=true`, `loop=false`, opacity 1. `size` menerima UDim2 atau struktur slot yang terdokumentasi dan `anchor` Vector2. Jika fallback poster hilang tampilkan teks dan reason code.

`Resolve(request, context) -> {ok, backend?, capability, reason?, suggestedConversion?, fallback?, permissionState}`. `permissionState` dimulai unknown sampai load probe. Tidak ada HTTP dari resolve. Sumber baru melewati idle → pending → ready/failed; play state separate stopped/playing/paused; hide policy pause, release atau preserve. Ganti sumber/tutup window menaikkan generation, batalkan timer/connection, lepaskan sprite dan instance/audio ref-count. Simpan cache menurut normalized source + version + host/permission epoch. Slot mendukung hero/logo/splash/topbar/background/section/card/tooltip/toast/modal/footer/widget dan portal berizin. Handle menyediakan `SetSource/SetPosition/SetSize/SetSlot/SetFit/SetPoster/Play/Pause/Stop/Seek/SetVolume/Destroy`. Jenis yang tidak mengizinkan seek/volume melaporkan `UNSUPPORTED_OPERATION`.

Validasi parser HTTPS: canonical host berlabel exact allowlist, no userinfo/port luar policy, query/token disanitasi, batas URL, size/timeouts. YouTube menerima ID 11 karakter alfabet URL-safe dan URL watch/short/share dari host yang diizinkan. Parser mengambil ID dan merekonstruksi URL kanonik tanpa parameter terselubung. Metadata adapter opsional, dipilih oleh developer, dengan ketentuan platform dan cache expiry. Asset fallback hanya memakai poster milik pengguna/yang diizinkan. Link membutuhkan tindakan pengguna dan kebijakan platform, termasuk QR atau cara menampilkan alamat. Jalur CDN/R2 ialah download build-time dari sumber berizin, decode di sandbox tooling dengan batas ukuran/waktu/format, transcode sesuai Roblox, upload oleh pemilik yang sah, tunggu moderasi dan grant experience, lalu tulis checksum dan ID dari hasil upload. Video YouTube tidak ditranscode dari stream-nya. [YouTube API policies](https://developers.google.com/youtube/terms/developer-policies) · [Roblox Community Standards](https://about.roblox.com/community-standards) · [Roblox asset operations](https://create.roblox.com/docs/cloud/reference/features/assets)

GIF/APNG/WebP: decode composited frames dengan disposal dan alpha, rekam ukuran, offset, trim, lama tiap frame dan loop; pack sheets dengan padding, masing-masing page punya checksum/permission. Playback pakai elapsed monotonic, cumulative frame intervals, seek, reverse, rate, ping-pong, skip frame secara bounded, marker dan visibility. Load halaman berikutnya terbatas, pause atau poster dalam reduced motion. Media disabled/offline tetap menyisakan visual yang terbaca. Background noninteraktif dan tidak menelan tap. Rencana fitur frame: image gallery/lightbox/zoom/pan/nine-slice/parallax opt-in; video play/pause/loop/timeline/poster/caption/full-window/dock/playlist dan eksperimentasi crossfade tergantung batas engine.

## Audio

`MusicLogin/Main/Loading/Ambient` dan `SfxUI/Success/Error/Notification/Custom` adalah bus terpisah dengan scoped owner dan satu mixer arbitration. Nonspatial, Volume master × bus × track, clamp, default tidak autoplay audible, mute berlaku segera, restore preferensi tanpa otomatis mulai main. Login→main sesudah auth sukses menggunakan dua suara dengan fade berbarengan jika siap, jika gagal hentikan/fade sesuai kebijakan, tidak buat lifecycle ganda. Playlist punya queue, repeat, shuffle, intro, crossfade dan timestamp; hide pilih pause/duck/mute; per-event cooldown/priority/dedup, target maksimal 8 voice SFX konfigurabel, slider/hue max event per waktu. SFX untuk hover/press/release, toggle, slider step/drag, dropdown, color picker, modal, tab, notice, login, wizard, window/snap, dan command. `Silent` dirancang sebagai registry kosong eksplisit. Feather, Noir Film, Jade Chimes, Cosmic Pulse, Arcade, Glass, Mechanical, Paper, Retro Terminal menunggu aset berizin; tidak ada ID produksi di Fase 0. Uji MED-10 crossfade, batas suara, consent, denied, hide, window berubah dan destroy kembali baseline.

## English handoff

Source syntax, capability verdict, asset permission and actual rendering are separate checks. Roblox asset IDs are the first-party path. R2/CDN and local files usually need a permissioned import pipeline. YouTube is a poster/card with a policy-gated external action. The atlas animator replays converted frames, and audio composition keeps music scenes separate from bounded SFX buses.

Dalam native Roblox, Community Standards membatasi display URL dan tindakan pengalihan eksternal. Poster/keterangan harus dapat digunakan tanpa menampilkan alamat atau QR terlarang. Tombol pembuka browser pada mode eksternal hanya tersedia setelah izin host dan policy host dibuktikan. [Roblox Community Standards](https://about.roblox.com/community-standards)
