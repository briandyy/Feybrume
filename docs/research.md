# UI library references

Sources inspected on 18 November 2026 (MYT). A link may point to a pinned commit or a rolling documentation page. D marks first-party material, F a fork or mirror, S a secondary source, and U an unverified identity. Observations come from the linked source. Third-party runtime behavior was not tested, and the sources are reference material only. Follow the fixture IDs for Feybrume-specific comparisons.
