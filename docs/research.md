# Matriks riset library UI

Tanggal pemeriksaan **18 November 2026 (MYT)**. SHA di bawah adalah referensi versi yang ditemukan; jika evidence berupa dokumentasi bergerak dan tidak bisa dipasangkan dengan SHA, baris menyatakan sumber rolling. `D` bukti di repo/dokumentasi pemilik, `F` repo fork/mirror yang diidentifikasi, `S` hanya sinyal sekunder, `U` belum terverifikasi. Semua adaptasi Feybrume **NOT_IMPLEMENTED** dan diuji nanti pada perangkat yang dicantumkan di [rencana QA](qa-and-backlog.md). Hanya pola abstrak yang diadopsi, dengan desain orisinal. Kode, ikon, animasi, aset, identitas visual dan loader proyek rujukan tidak menjadi dependensi.

## English handoff

The matrix records owner-authored evidence, forks, mirrors, and unresolved identities separately. Each row ties an observed design pattern to a Feybrume subsystem and a future acceptance test. Version references are recorded wherever independently available.
