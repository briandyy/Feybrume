# 技术概览

[English](../index.md) · [Bahasa Indonesia](../id/reference.md) · [简体中文](reference.md)

- **结构。** Luau 核心负责服务、事件、可取消任务、资源所有权及状态更新。主题引擎读取预设并解析控件样式。窗口设计将在布局切换时保留控件 ID 和状态。[架构（英文）](../architecture.md)
- **触屏。** 内置预设的触控目标至少为 48×48。窗口设计考虑安全区、刘海屏、旋转、系统按钮和屏幕键盘。输入、对话框与导航仍需在真机上验证。[移动端方案和测试（英文）](../mobile.md)
- **字体。** 主题引擎使用 Roblox 原生字体，并按字体角色回退。字形图集字体库仍在规划中。目标为 1,000 个字体家族，目前在 Feybrume 中完成渲染验证的数量为 0。[字体和许可计划（英文）](../typography.md)
- **媒体。** 原生图像、视频和音频需要类型和权限合适的 Roblox 资源。GIF 需要转换为精灵图，VideoFrame 无法直接播放 YouTube 网址。CDN 与本地文件依赖资源导入流程及宿主能力。[媒体矩阵（英文）](../media.md)
- **权限。** 设计支持免密钥、本地、供应商、网关与混合模式。特权操作由服务器验证。供应商与网关组合仍待联调。[身份验证与网关（英文）](../auth.md)
- **验证。** CLI 测试覆盖核心模块、预设、对比度和减少动效。Roblox Studio 与真机检查仍待执行。[质量与路线图（英文）](../qa-and-backlog.md)
